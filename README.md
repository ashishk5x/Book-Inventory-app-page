## 🎯 CSS Attribute Selectors Used

This project focuses on CSS Attribute Selectors.

### Exact Match

```css
tr[class="read"]
```

Targets rows whose class is exactly `read`.

---

### Starts With

```css
span[class^="rate"]
```

Targets every span whose class starts with `rate`.

Examples:

```html
<span class="rate one"></span>
<span class="rate two"></span>
<span class="rate three"></span>
```

---

### Contains Word

```css
span[class~="one"]
```

Targets elements whose class list contains the word `one`.

Example:

```html
<span class="rate one"></span>
```
